# Damage Agent

Ask a Pokémon Champions damage question with an attacker, defender, and move.
Use Champions points for stat investments, including amounts you call EVs.

Use **New chat** in the sidebar to start a separate conversation. Your chats are
saved in a shared library and can be reopened without logging in.

Each chat remembers its battle. After a calculation, try “what if it crits?”,
“give the defender Reflect”, or “remove its item”. Start a new chat for a fresh
battle, or explicitly ask to start a new battle in the current chat.
